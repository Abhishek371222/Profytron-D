## Fixes Applied

### Single fix: refund entitlement revoke

On **full** refund (`amount ≥ payment.amount`):

1. Cancel platform `UserSubscription` by `paymentId` (fallback planId + non-trial ACTIVE).  
2. Cancel marketplace `UserStrategySubscription` when metadata has `strategyId`.  
3. Demote `subscriptionTier` if no remaining ACTIVE platform plan.  
4. Claw back `MARKETPLACE_SALE` via `creator_credit_*` / invoice keys.  
5. Deposit clawback query restricted to `type: DEPOSIT` (avoid false match).  

Partial refunds: payment status path unchanged; **no** full entitlement cancel.
